# Development Plan

This project follows the POC defined in [concept.md](concept.md).

1. Create a `backlog/` folder with short feature descriptions.
2. Write a design specification for each backlog feature.
3. Write a system architecture document.
4. Record development and operational details: packages, local serving, and test setup.
5. Implement the game from those documents.
6. Test the completed game and multiplayer flow directly in two browsers.

Each stage leaves its documents in this repository before the next stage begins.
The concept document remains the source of scope; this plan does not add features
or technical requirements beyond it.
