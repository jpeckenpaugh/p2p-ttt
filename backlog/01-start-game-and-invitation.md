# 01 — Start a game and create an invitation

## Purpose

Let a host create a new local Tic-Tac-Toe match and obtain a shareable invitation link to send through an ordinary channel.

## Acceptance criteria

- A visitor can choose **Start a game** from the static application.
- Starting a game creates a new local match for the host.
- The application presents a shareable invitation link for that match.
- The host can copy the link and send it outside the application.
- The application clearly indicates that the invitation has been created and that the host is waiting for a reply.
